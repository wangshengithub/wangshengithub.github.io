肝了半个月，我把宫崎骏的夏天做成了网页游戏

  • 导航
  • 开发
  • 游戏

在这个万物皆可”卷”、连游戏都要每天打卡清日常、算攻击、盯倒计时的时代，你有多久没有体会过纯粹放松的感觉了？

结束了一天疲惫的工作和学习，面对满屏的3A大作或是重度抽卡手游，有时候我们连点击”开始游戏”的力气都没有。我们似乎太习惯在游戏里追逐战力、焦虑倒计时，却忘了游戏最初带给我们的，应该是避风港般的治愈。

作为一个向往宫崎骏动画里那种慢节奏田园生活的前端开发者，我决定自己动手，在代码的世界里盖一座小木屋。

大概肝了大半个月，在AI的辅助下烧了数十亿Token，经历了无数次推倒重来、修Bug修到头秃的夜晚，我终于把这个名为 《风铃谷的四季 (Chime Valley)》 的小游戏做出来了。

说实话，一个人（加上AI）做游戏真的很难。从底层逻辑、数值策划到美术像素动画的适配，每一个环节都是坑。虽然目前游戏已经能完整跑通，但可能偶尔还会藏着一些小Bug，如果遇到了，还请大家多多包涵，在评论区告诉我，我一定光速滑跪修复！

今天，想把这个没有KPI、没有Game Over，只有山谷的风和老屋灯光的小世界分享给你们。

👉 在线游玩： https://chime-valley.pages.dev/

🌿 56天的慢时光，时间就是用来浪费的

市面上的农场游戏，往往伴随着季节倒计时的焦虑。但在风铃谷，一年有56天，春夏秋冬各14天，季节会真实地流转。

春天种下土豆和胡萝卜，夏天去溪谷收获蓝莓，秋天是南瓜和向日葵的金色季节，冬天则种下耐寒的甜菜根。

这里没有任何失败惩罚。你不需要卡点上线收菜，因为时间只和体力和睡眠挂钩。你不需要精打细算体力，累了就回老屋睡一觉。它不会催促你，你可以完全按照自己的节奏生活。

🍲 灶台里的烟火气，和推开门时的惊喜

我特别喜欢游戏里的”做饭”和”布置”系统。从森林里采集食材，回到老屋的灶台前熬一锅南瓜浓汤，或者烤一份奶奶的蜂蜜蛋糕。如果运气好触发了”大成功”直接做出三份，那种小确幸真的能让人开心很久。把料理送给镇民，好感度就会悄悄上升。

当你用壁炉、摇椅和秋千椅等25件家具把小屋布置起来，家的”温度”就会慢慢上升。最让我感动的一个设定是：当家的温度升到2级以上，清晨会有镇民来敲门做客。温度越高，他们来得越频繁（满级甚至有80%的概率），那种”被惦记着”的感觉格外温暖。

🦌 藏在森林里的精灵，和不说再见的镇民

吉卜力的世界怎么能少得了精灵呢？ 屋檐下的风铃里住着陪伴你的”叮当”（第3天清晨就会主动现身）；夏天的晴空，去溪谷抬头看看天会遇到云朵羊；夏夜把体力耗尽让天黑下来，才会遇见萤火虫群；修好木桥后，送溪水獭3颗鹅卵石，它就会在溪边陪你；还有秋天密林深处雨夜才发光的蘑菇灯，和冬天雪夜山丘上的雪兔……集齐图鉴后，这9只小家伙甚至会跑到你的田里来做客。

除了精灵，山谷里还有7位性格迥异的镇民。沉默的木匠岩伯、旧书铺的顾先生、黏人的小女孩豆豆……帮苏婆婆盘点货物、帮邮差小飞找回失联的笔友、陪豆豆搭树屋。当好感度拉满，他们还会把拿手菜的秘方偷偷塞给你。

游戏有双结局。当你收集齐散落在各处的12段回忆，拼凑出奶奶不为人知的往事，达成真结局《风铃传承》时，你会明白”传承”的意义。当然，通关后你可以留在自由模式，继续过着日出而作、日落而息的退休生活。

💻 一点开发者的”小执念”与技术浪漫

作为一个程序员，在做这个项目时，我定下了一个可能有点”反主流”的规矩： 零框架、零构建、零 npm 依赖。

整个游戏纯靠 HTML5 + CSS3 + 原生 JavaScript，为什么这么折腾？因为我想让它做到真正的 “点开即玩”。

不需要下载几十个G的安装包，不需要配置复杂的环境。只要点开链接，推开那扇熟悉的木门，山谷的风就会立刻吹到你面前。存档用的是带损坏兜底的 localStorage，安全感拉满。

为了配得上这份治愈，我强烈建议你戴上耳机——因为我为春夏秋冬，分别准备了专属的主题曲。

🌟 最后，一点小小的私心

《风铃谷的四季》不仅是一个游戏，也是我作为一个开发者交出的一份答卷。项目目前已经完全开源！

如果你体验后觉得这个小世界还不错，恳请大家去我的 GitHub 仓库点一个免费的 Star ⭐！

👉 GitHub 仓库地址： https://github.com/wangshengithub/chime-valley

这数十亿Token没有白烧，大半个月的黑眼圈也没有白熬，你们的每一个 Star，都是对我这个独立开发者最大的鼓励，也是我继续用代码创造浪漫的动力！

👉 在线游玩地址（官网）： https://chime-valley.pages.dev/ （手机端和电脑端浏览器都可以直接玩，存档会自动保存在本地哦）

如果你也累了，想找个地方放空一下大脑，欢迎来风铃谷做客。
